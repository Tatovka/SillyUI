🖼️ **SillyUI** is retained gui framework with message system 🤓

🧐 The main goal is to provide user a bunch of instruments for constructing new widgets, laying all responsibility to compose and render everything on library.

🐘 Bases on Raylib btw for now, although I'm aimed to make it independet of graphic API in the future.

But it is all in future,now it is just a bunch of ugly widgets and raw dirty code 😈
